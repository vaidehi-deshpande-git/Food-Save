# FoodSave - Food Donation Management System

## 1. Introduction

FoodSave is a web-based Food Donation Management System.
It helps users donate extra food and manage food donation records.

The main purpose of this project is to reduce food wastage
and help people by making unused food available for donation.

## 2. Project Objectives

- Reduce food wastage.
- Encourage food donation.
- Manage food donation records.
- Track food expiry dates.
- Provide an easy-to-use donation platform.

## 3. Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- MongoDB
- Mongoose

## 4. Main Features

- Home Page
- Food Donation Form
- Save Donations in MongoDB
- View All Donations
- Search Food by Name and Location
- Filter Valid and Expired Food
- Edit Donation Details
- Delete Donation Records
- Admin Dashboard
- Responsive Design

## 6. Installation

First, install Node.js and MongoDB.

Open the project folder in VS Code.

Open the terminal and run:

```bash
npm install express mongoose
```

## 7. Database Configuration

MongoDB database name: FoodSave

Connection URL:

```text
mongodb://127.0.0.1:27017/FoodSave
```

## 8. How to Run the Project

Open the terminal in the project folder.

Run:

```bash
node express-server.js
```

Open your browser and visit:

```text
http://localhost:5000
```

## 9. Conclusion

FoodSave is designed to reduce food wastage
and promote food donation.

It provides a simple platform to add, view,
search, edit and delete food donation records.
